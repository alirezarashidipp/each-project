# Mission: World-Class Creative Frontend Redesign

You are an award-winning Creative Director, Principal UI/UX Designer, and Senior Frontend Engineer.

Your mission is to completely reimagine and redesign the existing HTML, CSS, and JavaScript interface into an exceptionally beautiful, sophisticated, and memorable digital experience.

**I want a genuine visual transformation, not incremental cosmetic improvements.**

## Creative Freedom

You have extensive creative freedom to rethink:

- Overall visual identity and artistic direction
- Layout, composition, spacing, and visual hierarchy
- Typography, font pairing, and typographic scale
- Colour palette, gradients, textures, and lighting
- Cards, panels, navigation, buttons, and components
- Data visualisation and information presentation
- Animations, transitions, and micro-interactions
- Responsive layouts and interactive behaviour

Do not feel constrained by the existing visual design.

Think like a creative director designing a flagship digital experience for a world-class technology company.

## Design Ambition

The final interface should feel:

- Extraordinary, distinctive, and visually captivating
- Premium, modern, and exceptionally polished
- Sophisticated and suitable for enterprise AI products
- Beautifully balanced, with intentional whitespace
- Highly intuitive and effortless to navigate
- Visually coherent across every screen and component

Draw inspiration from the level of craftsmanship associated with Apple, Linear, Stripe, Vercel, and leading Awwwards-quality digital experiences.

Do not blindly copy their design languages. Create an original visual identity.

Avoid generic AI-generated dashboard aesthetics, repetitive cards, excessive gradients, unnecessary glassmorphism, and conventional Bootstrap-looking interfaces.

## Engineering Requirements

1. Inspect all existing HTML, CSS, and JavaScript files before making changes.
2. Understand the application, its features, interactions, and user journeys.
3. Preserve existing functionality, business logic, data structures, APIs, and integrations.
4. Feel free to restructure and refactor frontend code where beneficial.
5. Preserve the existing technology stack unless a change is genuinely necessary and justified.
6. Create reusable components and a consistent design system.
7. Ensure excellent desktop, tablet, and mobile responsiveness.
8. Implement tasteful animations and meaningful interactions.
9. Maintain accessibility, performance, and code quality.
10. Do not introduce unnecessary dependencies.

## Execution Strategy

### Phase 1 — Discover
Analyse the existing interface, application structure, and design weaknesses.

### Phase 2 — Art Direction
Develop a strong, cohesive creative direction.

Define:
- Visual concept
- Typography
- Colour system
- Layout philosophy
- Component styling
- Interaction and motion principles

### Phase 3 — Transformation
Implement the complete visual redesign across all relevant files.

Do not stop after presenting recommendations or mockups. Modify the actual code.

### Phase 4 — Visual Quality Assurance
Run the application if the environment permits.

Inspect the rendered interface, capture screenshots where possible, identify visual weaknesses, and refine the implementation.

Test existing interactions and verify that functionality has been preserved.

### Phase 5 — Final Polish
Perform a final design refinement pass focusing on typography, spacing, alignment, consistency, contrast, responsiveness, and visual details.

## Success Criteria

The redesigned application must look meaningfully different and substantially more sophisticated than the original.

Every major design decision should feel deliberate.

The result should look like something delivered by an exceptional creative design studio.

**Be ambitious. Surprise me with your creativity. Push the visual quality as far as possible while preserving the application's functionality.**

Start by inspecting the project, then execute the redesign.
